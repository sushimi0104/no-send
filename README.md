# メッセージが送れない

ブラウザだけで動く、メッセージ動画作成ページです。アイコンと背景の画像は端末内で読み込み、サーバーへ送信しません。背景は未設定が初期値で、指定時は縦横比を保って会話エリアを覆います。受信音・送信音・入力音は Web Audio API で生成するため、音声ファイルは不要です。外部 JavaScript ライブラリは使っていません。

## GitHub Pages

このフォルダの `index.html`、`styles.css`、`app.js` をリポジトリのルートに置き、GitHub の **Settings → Pages** で **Deploy from a branch**、対象ブランチの **/(root)** を選びます。ビルドは不要です。

## 動画形式

ブラウザの `MediaRecorder` が対応する形式で保存します。H.264（映像）と AAC（音声）を明示して録画できる場合は MP4、それ以外は WebM です。単に「MP4 対応」と返すブラウザで VP9 入り MP4 が作られる問題を避けるため、コーデック指定のない MP4 は使用しません。WebM は iPhone への共有には向きません。音声トラックに対応しない場合は映像のみを保存し、その旨を画面に表示します。動画書き出しに対応していないブラウザでは、その旨を画面に表示します。

## 設定の保存

名前・テーマカラー・メッセージ1〜5・着信の設定は localStorage、選択したアイコン・背景画像は IndexedDB に自動保存します。サーバーへの送信は行いません。同じサイトを同じブラウザで再読み込みすると復元します。メッセージ4が空欄でもメッセージ5の入力を保持します。「全てクリア」「初期値に戻す」「外す」の操作も保存されます。ブラウザのサイトデータ削除やプライベートブラウズでは保持されないことがあります。保存に失敗してもその場での編集・再生は利用できます。
